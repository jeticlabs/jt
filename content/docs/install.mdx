The package is published as **`jetic-cli`**. The executable is **`jetic`**.

## Requirements

- **Node.js** `>= 20`
- **pnpm** `>= 9` only when building from source

## Global install

```bash
npm install -g jetic-cli
jetic --help
```

## Run without installing

```bash
npx jetic-cli --help
```

## Build from source

```bash
git clone https://github.com/jeticlabs/Jetic.git
cd Jetic

pnpm install
pnpm build

cd apps/cli
pnpm link --global
```

## Verify

```bash
jetic --help
jetic doctor
```

`jetic doctor` checks your Node version, configuration, adapters, and ports.
